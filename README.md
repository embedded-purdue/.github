# Organization profile

Source for the Embedded Systems @ Purdue GitHub organization profile.

Publish these files in the public `embedded-purdue/.github` repository with `main` as its default branch. GitHub displays `profile/README.md` on the organization's Overview page.

The included GitHub Actions workflow refreshes public repository, star, fork, and language counts daily and on manual dispatch. It uses the built-in `GITHUB_TOKEN`; no personal token or third-party stats service is required. Run **Update organization stats** once after publishing to populate the initial stats. Repository rules must allow the workflow to push updates to `main`.
